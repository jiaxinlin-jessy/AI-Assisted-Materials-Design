# Lab 3 — Final Project: Cohesive Energy Prediction with ML

**Lecture:** 8 | **Score:** Part of overall 98/100

## Overview

End-to-end machine learning project using the [MatPES](https://matpes.ai/) r2SCAN dataset — a database of ~400k DFT-calculated structures. The target property is **cohesive energy per atom (Eᶜ)**, a fundamental quantity for materials stability and interatomic potential fitting.

Three model families are trained, tuned, and compared on a blind prediction set.

## Tasks

| Question | Description | Points |
|----------|-------------|--------|
| 1–2 | Data loading and Eᶜ distribution analysis | 5 |
| 3 | Feature engineering — extended composition-based descriptors from `pymatgen` Element objects | 30 |
| 4 | Linear model (Ridge/LASSO) with CV, hyperparameter tuning, permutation importance | 10 |
| 5 | Tree model (HistGradientBoostingRegressor) | 20 |
| 6 | Neural network (MLPRegressor with early stopping) | 15 |
| 7 | Cross-model feature importance analysis and materials-science interpretation | 20 |

## Key results

- **Feature engineering:** Extended beyond Lab 2 — includes additional pymatgen `Element` attributes (electronegativity, ionisation energy, electron affinity, etc.), with mean/max/min/range aggregations
- **Model comparison:** Gradient boosted trees achieve the best MSE; neural network is competitive; linear model benefits most from regularisation
- **Feature importance:** Electronegativity-related features and atomic radius consistently rank highest across all three model types, consistent with their role in bonding strength
